TP N°1 : une page web HTML avec GitHub et GitHub Actions

Notre équipe

  • Achraf Aazza
  • Fatima Zahra Mouhib
  • Samir Labodja

Objectifs

  • Créer et gérer un dépôt GitHub
  • Cloner le dépôt en local
  • Développer une page web simple en HTML
  • Suivre les versions avec Git
  • Vérifier la qualité du code HTML avec GitHub Actions

Notre pipeline

  1. Nous modifions la page en local.
  2. Nous envoyons le code sur GitHub avec git push.
  3. GitHub Actions lance HTMLHint sur les fichiers HTML.
  4. Coche verte : le code est correct. Croix rouge : il faut corriger.
